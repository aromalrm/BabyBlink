# DeskDash image files

These are original illustrated stand-ins for the Ajman demo. They are not photographs and they are not taken from another shop. Replace a file in place to swap the art; the app reads the path, not the drawing.

Product art lives at `public/images/products/{id}.webp`, plus `{id}-b.webp` and `{id}-c.webp` for the other two frames. Heroes on the home screen are drawn in the page, not stored as files.

Regenerate the product set with:

```
node scripts/render-products.mjs
```
